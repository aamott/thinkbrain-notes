# Architecture Documents

These documents describe authoritative system design for the MVP and near-future architecture.

## Authoritative MVP Architecture

- `app-architecture.md`: repository layout, runtime boundaries, and data flow
- `ui-shell.md`: desktop layout and navigation model
- `workspace.md`: workspace folder behavior
- `notes.md`: Markdown note model and metadata policy
- `editor.md`: Markdown editor architecture
- `indexing-search.md`: file watching, indexing, SQLite cache, and search
- `settings.md`: settings levels and storage
- `git.md`: system Git integration
- `themes.md`: built-in theme foundation
- `extensions.md`: internal-only MVP contribution model

## Deferred Architecture

Future features live in `plans/deferred/` until explicitly promoted.

Do not implement deferred features during MVP work.
