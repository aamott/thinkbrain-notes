# Database Implementation

## Tech Stack
- SQLite
- FTS5 for full-text search

## Philosophy
- The database is an ephemeral, disposable cache of the vault.
- It is generated by the indexer.
- It is NEVER the source of truth. The markdown files are the source of truth.
- It is stored in the OS's hidden AppData/Config directory, never in the vault.

## Schema Architecture
- **Files Table**: path (PK), title, last_modified, hash (for diff detection).
- **Tags Table**: id, tag_name, file_path (FK).
- **Links Table**: source_path, target_path (powers [[WikiLinks]] and Backlinks).
- **FTS Virtual Table**: For fast text searching across markdown content.

## Indexing Process
- When a file is saved, a file watcher detects the change.
- The indexer intercepts the raw markdown, extracting `#tags` and `[[WikiLinks]]`.
- It updates the local SQLite database with new relationships.
