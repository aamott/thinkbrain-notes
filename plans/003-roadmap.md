# Roadmap

## MVP: Desktop Local Markdown Workspace

Goal: create a usable desktop note app with local Markdown files as the source of truth.

MVP includes:

- project scaffold
- desktop Tauri shell
- workspace opening
- file explorer
- Markdown note create/read/update/delete
- CodeMirror 6 editor
- frontmatter and Markdown metadata parsing
- basic search
- JSON settings
- basic system Git integration
- built-in theme foundation
- test/lint/typecheck/build workflow

See `plans/005-mvp-scope.md` for the authoritative MVP boundary.

## Phase 3: Platform and AI Features

Phase 3 items are intentionally out of MVP scope.
