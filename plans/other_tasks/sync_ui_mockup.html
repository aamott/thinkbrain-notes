Sync & History UI Redesign

Interactive Mockup

Comparing UI approaches for single-document git diff history and the renamed "Sync conflicts" panel.

Core Problem Identified

The app currently renders two separate sync icons on the left Action rail: Decisions needed (conflicts) and Saved versions (repository-wide history). Nobody wants to roll back an entire notes vault to last Tuesday. Instead, users want single-document version history with a visual git diff, while keeping sync conflicts clean, accessible, and actionable.

Approach 1 Right Dock

Action Items Inspector

Place Version History in the right-side Action items menu (alongside Outline, Properties, Backlinks). Left Action bar is reduced to 1 sync item: Sync conflicts.

✓ Architecturally clean (Right side = Document scope)
✓ Maps directly to mobile ActionItemsMenu
⚠ Right sidebar (320px) is tight for wide diffs
Approach 2 Editor Header

Note Header & Diff Tab

Attach a ... menu directly to the active note tab / document header. Selecting "History" opens a dedicated full-width Diff Tab.

✓ Maximum space for side-by-side git diffs
✓ Zero clutter on both left and right rails
⚠ Navigates away from the live markdown editor
Recommended
Approach 3 Unified Hybrid

Right Inspector + Quick Diff Tab

Combines both: History timeline lives in the Right Inspector (accessible from top-right Action Items & mobile menu), with an instant "Compare Diff" button that opens our rich visual diff viewer.

✓ Quick revision scrubber without leaving note
✓ One click to open full-fidelity chunked diff
✓ Works identically on Desktop and Phone
