- description: `const checked = Boolean(value)` (line 19) coerces any `unknown` value to a boolean. If the store ever holds a non-boolean for a boolean-typed setting (e.g. a migrated/corrupted value such as the string `"false"`, the number `0`, or `null`), `Boolean("false")` yields `true` and `Boolean(0)` yields `false` — the toggle renders a state that does not reflect the actual stored value, and clicking it calls `onChange(!checked)` which writes a real boolean, silently "fixing" the corruption without any signal. This is a defensive-coercion tradeoff: it prevents a crash but hides the type mismatch that the registry's validation layer is supposed to surface. Consider rendering the toggle as "indeterminate"/disabled when `typeof value !== "boolean"`, or logging a warning, so a schema/persistence bug is visible rather than masked.
