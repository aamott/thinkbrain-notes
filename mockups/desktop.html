# Thinkbrain Roadmap
 
A personal knowledge base and notes app for simple people.
 
## MVP Milestones
 
- [x] Project scaffold
- [x] Desktop Tauri shell
- [ ] Workspace & file explorer
- [ ] Note model & Markdown parser
- [ ] CodeMirror editor
- [ ] Indexer & search
- [ ] Settings
- [ ] Git integration
 
## Architecture
 
The app uses a clean three-layer separation:
 
1. **React frontend** — UI, layout, editor, state
2. **packages/core** — platform-agnostic logic
3. **Tauri/Rust** — native filesystem, Git, SQLite
 
See [[app-architecture]] for the full breakdown.
 
## Key Decisions
 
> Notes are plain Markdown files on disk. No database, no proprietary format.
 
**Tech stack:**
 
- Tauri v2 + React + TypeScript + Vite
- CodeMirror 6 for the editor
- Zustand for state management
- SQLite FTS5 for search indexing
